# 📱 Mobile Sales Dashboard – Power BI

## 📌 Project Overview

The **Mobile Sales Dashboard** is an interactive Power BI dashboard designed to analyze mobile phone sales performance across different dimensions such as mobile model, brand, city, payment method, customer ratings, and time.

The dashboard provides an overview of key sales KPIs and allows users to interactively analyze sales trends using filters and time-based analysis. It also includes **Month-to-Date (MTD)** analysis and **Same Period Last Year (SPLY)** comparison to help understand sales performance over time.

---

## 🎯 Project Objectives

- Monitor overall mobile sales performance
- Analyze sales by mobile brand and model
- Understand customer purchasing behavior
- Analyze transactions by payment method
- Analyze sales performance across cities
- Track monthly sales quantity trends
- Analyze customer ratings
- Compare current performance with the same period in the previous year
- Provide an interactive dashboard for business reporting and decision-making

## 📊 Dashboard KPIs

The dashboard provides the following key performance indicators:

| KPI | Description |
|---|---|
| Total Sales | Total revenue generated from mobile sales |
| Total Quantity | Total number of mobile units sold |
| Average Price | Average selling price of mobile phones |
| Transactions | Total number of transactions |

## 📈 Dashboard Features

### 1. Mobile Sales Dashboard

The main dashboard provides an interactive overview of mobile sales performance.

Key visualizations include:

- Total Sales
- Total Quantity
- Average Price
- Total Transactions
- Total Sales by City
- Total Quantity by Month
- Customer Ratings by Rating Status
- Transactions by Payment Method
- Total Sales by Mobile Model
- Total Sales by Day Name
- Brand-wise Sales and Transactions

### Interactive Filters

Users can filter the dashboard using:

- Mobile Model
- Brand
- Payment Method
- Year / Quarter / Month / Day
- Individual months

---

### 2. MTD Analysis

The dashboard includes **Month-to-Date (MTD)** analysis to track sales performance over time.

The MTD report provides a time-based view of sales performance across different years and quarters.

This helps identify:

- Sales growth and decline
- Periods with higher/lower sales
- Changes in sales performance over time
- Quarterly and yearly trends

---

### 3. Same Period Last Year Analysis

A separate dashboard page is used for **Same Period Last Year (SPLY)** analysis.

This allows current-period performance to be compared with the corresponding period from the previous year.

The comparison helps users understand year-over-year changes in sales performance.
